# 市场状态分析（独立任务）

> 分析 6 大指数（上证指数 sh000001、深证成指 sz399001、创业板指 sz399006、沪深300 sh000300、中证500 sh000905、中证2000 cs932000）的走势，输出**市场状态（大势）→ 市场风格（大小盘/成长价值）→ 市场结构（分化/宽度/领头）**三维结论，落盘 `/home/agentuser/data/定时任务打包/data/market_state_<数据日期>.md`，供 daily-market-summary（19:30）、个股快速分析、趋势跟随链路等其他任务引用。

## 输入

无（自动拉取）；或用户指定日期（历史复盘）。

## 执行流程

### 第1步：生成六大指数断面（脚本）

```bash
python3 /home/agentuser/.hermes/scripts/market_state_prep.py [YYYY-MM-DD]
```

- 无参数默认今天；传参用于历史复盘
- 输出：`/tmp/market_state/index_data_<拉取日期>.txt`（断面表格 + 分化度）与 `.json`
- **先读断面文件确认 `数据日期`（data_date）**：遇节假日/周末，K线止于最近交易日；后续所有"当日"表述以 data_date 为准
- 断面含：6指数收盘/当日%/MA5/10/20/60/趋势初判/位置分位（近60日高低区间百分位）/5·20·60日涨幅/距20日高点/20日涨幅排名 + 当日分化度（极差/标准差/均值）
- ⚠️ 中证2000 必须用 **cs932000**（中证指数公司前缀 cs，腾讯接口支持；sh/sz 前缀返回 HTTP 400）

### 第2步：拉取市场宽度（涨跌家数）

```bash
node /home/agentuser/.hermes/skills/westock-data/scripts/index.js changedist hs <数据日期>
```

- 市场参数必须写 `hs`（沪深），不写默认返回美股空数据
- 返回：沪深总数/上涨/下跌/平盘/涨停/跌停
- 计算：上涨占比 = 上涨÷总数；涨跌比 = 上涨÷下跌；判断市场宽度强弱
- 可选交叉验证：东财 push2 实时接口 `https://push2.eastmoney.com/api/qt/ulist.np/get?fltt=2&secids=1.000001,0.399001&fields=f2,f3,f12,f14,f104,f105,f106`（f104=上涨家数/f105=下跌/f106=平盘，指数维度）

### 第3步：三维分析（核心推理，逐维下结论）

**① 市场状态（大势）**
- 各指数趋势初判（断面"趋势初判"列）：多头排列/偏多/震荡/偏空/空头；统计 6 指数中偏多 vs 偏空数量 → 大势定性
- 位置：位置分位高低（近60日区间），多数指数处于高位区（>66%）还是低位区（<33%）
- 量能/宽度：上涨占比、涨跌比、涨停跌停数；成交量变化（断面 VOL 可对比5日均量，或看宽度）
- 当日 vs 近期：当日分化度（均值/极差）→ 普涨普跌 or 分化
- 结论句式：**当前市场处于【趋势/震荡/下跌】+【普涨/普跌/分化】+【高位/中位/低位】**

**② 市场风格**
- 大小盘：沪深300（大盘） vs 中证500（中盘） vs 中证2000（小微盘）的 5日/20日/60日涨幅对比 → 大/中/小盘谁占优
- 成长/价值：创业板指（成长） vs 沪深300（价值权重）相对强弱
- 风格动量：近5日 vs 近20日涨幅排名变化 → 风格是否在切换（用断面20日排名 + 5日排名对比）
- 结论句式：**当前风格【大盘/均衡/小盘】占优，【成长/均衡/价值】占优，风格【稳定/切换中】**；若中证2000 与沪深300 20日涨幅差>3pp 判"小盘占优"，<-3pp 判"大盘占优"，否则均衡

**③ 市场结构**
- 分化度：断面分化度（极差pp/标准差pp）→ 极差>2pp 分化明显、<1pp 一致
- 宽度：上涨占比>60% 强势普涨、40-60% 中性、<40% 弱势；结合涨停/跌停（跌停多=风险释放）
- 领头/落后：20日涨幅排名第一指数（风格引领者）与最后指数（主跌方向）
- 权重 vs 题材：沪深300/上证（权重） vs 中证2000/创业板（题材/成长）谁领涨 → 结构健康度
  - 权重题材齐涨=健康；仅题材涨权重弱=存量博弈；权重独涨题材跌=防御结构
- 主线衔接（增强项，有则看）：`industry_themes` MAX(theme_date) 主线状态，判断市场结构是否由主线支撑
- 结论句式：**市场结构【一致/分化】，【权重/题材/均衡】主导，领涨为【XX】，结构【健康/脆弱】**

### 第4步：综合结论 + 策略含义

- 一句话定性：状态×风格×结构 → 如"震荡市低位区、小微盘占优、题材存量博弈"
- 对趋势跟随策略的含义（供其他任务引用）：
  - 仓位倾向：强势普涨=可积极；弱势普跌=降暴露/防守；分化=结构性机会
  - 风格倾向：大小盘/成长价值哪个占优，选股/持仓倾向对应
  - 风险提示：领跌方向、跌停数、破位指数
- 明确标注数据截至日期；遇节假日注明"（今日<节日>休市，数据截至<上一交易日>）"

写报告到 `/home/agentuser/data/定时任务打包/data/market_state_<数据日期>.md`（数据日期=断面 data_date，非拉取日）。格式见下方模板。

## 关键陷阱

1. **中证2000 代码 = cs932000**（腾讯 finance_wrapper 支持，含MA；sh/sz 前缀 400 报错）
2. **changedist 必须带市场参数 `hs`**，否则返回美股空数据
3. **数据日期 ≠ 拉取日期**：周六/节假日拉取，K线止于最近交易日；报告中所有"当日"以断面 data_date 为准，标题写"数据截至 <data_date>"
4. 趋势初判是规则初判（脚本），Agent 结合各指数MA排列与上下文修正，不机械照抄
5. 风格结论要有数值锚点（20日涨幅差 ±3pp 阈值），禁止无依据定性
6. 落盘目录固定 `/home/agentuser/data/定时任务打包/data/`，文件名用**数据日期**（与其他环节 YYYYMMDD 命名对齐，daily-summary 按日期引用）
